# AAC Book Store — Website Project

## Live Demo
👉 [Visit Website](https://ceophamduchung01.wixsite.com/aacstore)

## Overview
This website was developed as part of my *Web Programming* course to design a dynamic and user-friendly educational e-commerce platform.  
It showcases collections of Software Engineering and Programming books with a clean UI/UX, responsive layout, and clear content hierarchy.

## Tools Used
- **Wix Editor** — For drag-and-drop page design and layout creation  
- **Content Manager** — For managing book details, prices, and categories  
- **Sections & Dynamic Pages** — For reusable design and responsive structure  
- **Built-in SEO Settings** — For optimizing site visibility  

## Learning Outcome
- Gained experience in using no-code tools to build a professional website  
- Improved understanding of UI/UX design principles  
- Learned to organize product data using content management system  
- Practiced structuring multi-section pages and navigation flow
